****

Data and R code accompanying:

<b>Fed or famished: The role of food availability in the physiological and behavioural responses of <i>Dermasterias imbricata</i> to prolonged thermal stress</b>

Authors: [Dominique G. Maucieri](https://dominiquemaucieri.com), Iria Gimenez, Kate Rolheiser, Alyssa-Lois M. Gehman, Brenna Collicutt, Agnes Djioua, Jacob M. Etzkorn, Bradford Vinson, and [Amanda E. Bates](https://www.oceanconservationlab.com/)

****

[01_raw_data](01_raw_data/)

* [AFDM_measures.xlsx](01_raw_data/AFDM_measures.xlsx): Ash-free dry mass data for Experiment One.
* [biooracle](01_raw_data/biooracle): Bio-ORACLE data for sea surface temperatures experienced in each latitudinal band within approximately 500m of shore.
* [Coelomocyte_Counts.xlsx](01_raw_data/Coelomocyte_Counts.xlsx): Coelomocyte count data for Experiment One.
* [Experiment_Data.xlsx](01_raw_data/Experiment_Data.xlsx): Extraction, righting, feeding, mortality and tube feet collection data for Experiment One. 
* [Hyacinthe_Buoy](01_raw_data/Hyacinthe_Buoy): Long-term temperature records from Hyacinthe Bay.
* [Konecny_etal_2021](01_raw_data/Konecny_etal_2021): Tidepool monitoring data collected on the west shore of Quadra Island by Konecny et al. (2021).
* [LS_Experiment_Data.xlsx](01_raw_data/LS_Experiment_Data.xlsx): Respirometry and resistance time data for Experiment Two.
* [LS_Feeding_Log.xlsx](01_raw_data/LS_Feeding_Log.xlsx): Feeding data for Experiment Two.
* [LS_Physical_Characteristics.xlsx](01_raw_data/LS_Physical_Characteristics.xlsx): Physical Charactersitics for sea stars in Experiment Two.
* [SeaStar_Physical_Characteristics.xlsx](01_raw_data/SeaStar_Physical_Characteristics.xlsx): Physical Charactersitics for sea stars in Experiment One.
* [temp_loggers](01_raw_data/temp_loggers): Tank temperature loggers for Experiment Two.


[02_scripts](02_scripts/)

* [experiment_1_analysis.pdf](02_scripts/experiment_1_analysis.pdf) and [experiment_1_analysis.Rmd](02_scripts/experiment_1_analysis.Rmd): Script and knit pdf file for code used in the analysis of Experiment One.
* [experiment_1_treatment_assignment.Rmd](02_scripts/experiment_1_treatment_assignment.Rmd): Code to produce the treatment assignments for Experiment One.
* [experiment_2_analysis.pdf](02_scripts/experiment_2_analysis.pdf) and [experiment_2_analysis.Rmd](02_scripts/experiment_2_analysis.Rmd): Script and knit pdf file for code used in the analysis of Experiment Two
* [experiment_2_treatment_assignment.Rmd](02_scripts/experiment_2_treatment_assignment.Rmd): Code to produce the treatment assignments for Experiment Two.
* [experiment_2_metabolic_calculations.Rmd](02_scripts/experiment_2_metabolic_calculations.Rmd): Code to clean up metabolic data for Experiment Two.


[03_cleaned_data](03_cleaned_data/)

* [AFDM_clean.csv](02_scripts/AFDM_clean.csv): Summarized AFDM data for Experiment One.
* [metabolic_rates.csv](02_scripts/metabolic_rates.csv): Cleaned metabolic rate data for Experiment Two.
* [SeaStar_Physical_Characteristics_wAssignments.csv](02_scripts/SeaStar_Physical_Characteristics_wAssignments.csv): Treatment assignments and physical characteristics data for Experiment One.
